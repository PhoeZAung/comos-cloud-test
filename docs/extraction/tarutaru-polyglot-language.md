# Tarutaru — Polyglot replacement and language choice

FFd20 source: https://finalfantasyd20.com/races/core-races/tarutaru/ (Alternate Racial Traits → Polyglot).

- Polyglot replaces Magic Expert (+2 Knowledge Arcana / Spellcraft removed). It gives an automatic **+2 racial bonus on Linguistics** and marks Linguistics a **class skill**, without adding skill ranks.
- Polyglot **modifies**, rather than removes, the Tarutaru Languages trait. Starting Common and Lalafellan remain. Select exactly **one freely chosen extra starting language**. The original normal high-Intelligence bonus-language list and capacity remain unchanged.
- The required Polyglot language appears on the existing **Ability Scores** step, using the FFd20 languages lookup/free-text field. It does not create a new wizard page. A player may select any other valid language, but cannot duplicate Common, Lalafellan, or already selected high-INT languages.
- The extra language exists even at Intelligence 10 or lower and does not consume an INT bonus-language slot. Different bonuses from high INT remain bounded by the existing seven-language pool.
- Strict source-operation mapping: a resolved whole-trait replacement for Magic Expert plus an allowlisted part-of-feature language modifier. Other unresolved partial replacements stay blocked.
- On deselection, the extra-language choice is pruned; after a character is saved, its selected alternate trait is permanent. Save/reopen retains all selected languages and correct racial skill bonuses.
- Manual-only behaviors outside Polyglot and other race variant mechanics remain in source descriptions.

Verification: automated character-creation and save/reopen fixtures; signed-in production creation/save/reopen and UI accessibility are separately manual checks.
