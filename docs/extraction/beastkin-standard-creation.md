# Beastkin standard-trait creation

Source: https://finalfantasyd20.com/races/base-races/beastkin/
Archived HTML SHA-256: `0797d628337476a96ebccf82c1be645e80fbfeff01700346ac6a322845d8e837`.

Standard Beastkin map +2 Strength, +2 Wisdom, −2 Intelligence, Medium humanoid/beastkin identity, land speed 30, Common/Beastmen, darkvision 60 feet and low-light vision. Hunter makes Stealth/Survival class skills; Keen Senses adds +2 Perception. Seven optional languages use the source list (Draconic, Dwarven, Elvaan, Galkan, Giant, Goblin, Orc) and the positive Intelligence modifier after the racial penalty.

Natural Armor contributes one owned point, and Fleet-Footed contributes two owned initiative points plus a manual Run feat card. Repeated recompilation does not accumulate these, manual adjustments and feat notes survive, and disabling/restoring the traits removes/adds only their own contributions. Sprinter's charge/run/withdraw +10 feet remains conditional, without changing base speed. Magic-sleep immunity, enfeebling/fear saves and Run resolution remain manual source references rather than global save, condition or speed changes.

Alternate traits are guarded. Favored rewards and independent full review remain pending; each class retains its existing progression boundary.
