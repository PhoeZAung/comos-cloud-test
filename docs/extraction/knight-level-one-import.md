# Knight first-level integration

Source: https://finalfantasyd20.com/classes/core-classes/knight/
Archived HTML SHA-256: `694ad6f5c4f764a1f8d2096144dda916618ad243335e024511cd65f0d1d18543`.

Knight first-level creation/editing requires Lawful Good, Lawful Neutral or Lawful Evil and uses d12 HP, BAB +1, Fortitude +2, Reflex +0, Will +2, 4 + Intelligence skill ranks and 175 gil. Proficiencies include simple/martial weapons, knight swords, all armor and shields including tower shields. Seven first-level reference cards retain proficiencies, Defensive Stance, Threat Control, Defend Ally, Code of Conduct and both Limit Breaks. Threat Control grants a separate manual Antagonize feat card whose edited notes survive recompilation.

Defensive Stance tracks daily rounds equal to 4 + permanent build Constitution modifier (clamped at zero). Recompilation preserves expenditure as capacity changes, and temporary sheet Constitution does not inflate the build-derived capacity. Restoration uses the correct Knight source and counter. Recovery is manual because the required eight hours need not be consecutive; generic rest does not silently reset it.

Stance attack/damage/Will/dodge modifiers, temporary HP and the one-minute replenishment restriction, movement/mount/fatigue/unconscious/rage conditions and fatigue recovery remain manual. Defend Ally's adjacent AC transfer, Antagonize/retry resolution, and Limit Break Protect/Shell/Regen or DR/resistance effects remain manual. They do not become permanent stats, spells, MP, healing or automated ally changes. The lawful code is shown; GM adjudication and later alignment changes through manual sheet overrides are not automated.

All twenty progression rows and later sections are retained for future review; no later talents, upgrades, archetypes or multiclass progression are enabled. Favored rewards and independent full review are pending.
