# Hume standard first-level creation

Source: https://finalfantasyd20.com/races/core-races/hume/
Archived HTML SHA-256: `4e3d6bff3b8aae3c990fd985984b8abd504fba5130f7376bacbf5aad7ad5d276`.

The Hume standard-trait milestone supports new first-level characters and editing those builds with each of the six current class compilers. The existing six-option score pool grants +2 to exactly one chosen score. Identity maps Medium size, humanoid/hume type, 30-foot land speed and Common. Integrated grants +1 Bluff, Disguise and Knowledge (local). Curiosity grants history/local Knowledge as class skills, while its conditional +2 checks for existing class skills and +4 gathering-information checks remain manual. Sociable remains a manual retry rule.

Skilled adds one rank after the class's Intelligence/minimum calculation. The same entitlement is used by preview, allocation validation and the sheet's budget, including sheet Intelligence edits and reopening. It is active only with the Hume Skilled standard trait; disabling that trait removes the entitlement. The Hume bonus feat has its own stable owned slot, separate from ordinary character-level and class-granted feats. Its selection, prerequisites and effects remain manual; naming the card and adding notes survive compiler saves. Disabling Bonus Feat removes only that owned slot.

High-Intelligence bonus languages use one free-text name per line rather than a fabricated short catalog. Names are stored as bounded language-choice values, displayed as escaped text and checked against the positive Intelligence modifier. Common is already known, case-insensitive duplicates and invalid/control markup are rejected, and choices require an active language trait. The field can record languages such as Al Bhed without falsely limiting the source's unrestricted choice to another race's list. This records user-supplied language names; it is not an independently reviewed universe of languages.

Variants, all alternate traits, favored rewards, multiclassing and progression above first level remain guarded for this milestone. Full source review, inheritance/RP mapping, conditional bonus stacking and language-learning progression remain separate work. This is partial testing support, not full race completion or independent rules approval.

Validation: 331 tests and the cloud build pass. Five Hume regressions cover all six compilers, score/extra-rank/extra-feat entitlements, language count/duplicate/inactive rules, manual-row preservation, disabled traits, scope guards and database persistence. Mobile browser evidence is saved separately after creation/edit/save/reopen checks through real routes with fixture authentication. Production provider login is not claimed.
