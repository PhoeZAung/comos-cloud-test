## Source limitation

The extractor GitHub repository contains tools only. Saved HTML/Markdown exports are not present. Stored text is checked verbatim against application definitions; original archive completeness is not certified. In particular, Archer and Bard contain short summary-style feature descriptions without a full companion field. No text was fabricated to replace those. Upload the extractor export ZIP from `workspace/exports/` to finish archive comparison and replace any remaining summaries with the saved source text.
