# Moogle Grounded + Speed popup

Official rules: https://finalfantasyd20.com/races/core-races/moogle/

- Grounded modifies Base Speed rather than replacing the full trait. Land remains 20 ft and is not reduced by medium/heavy armor, encumbrance or similar. It removes limited wing-assisted flight and its conditional Acrobatics bonus. The +1 racial save against effects reducing movement speed is situational and remains in the racial ability description, not all saving throws.
- Standard Moogle receives a seeded 20-ft limited Fly speed (clumsy) and retains the description of rounds, Constitution checks, loads, and rest.
- An exact source-ID whitelist enables only this part-of-feature modifier. The updated replacement engine grants the named Grounded alternate and retains the original Base Speed land effect.
- Seed movement fields only when missing; preserve manual edits (including explicit Fly 0). Initial choice of Grounded is permanent.
- Clicking the value of Speed in Identity opens a read-only popup of Land, Burrow, Climb, Fly, and Swim speeds, including unavailable values. Only the header Edit button edits movement fields. Fly maneuverability is not in the popup.
- Player/GM manual checks: Verify normal Moogle flight limitations and +4 Acrobatics while capable of flight; verify Grounded +1 saves only against speed reduction; test signed-in create/save/reopen and mobile popup keyboard accessibility.
- Race-only scope. No class, archetype, or shared queue changes.
