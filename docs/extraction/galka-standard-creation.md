Standard traits retain +2 STR, +2 WIS, −2 CHA, Medium humanoid/galka identity, 20-foot land speed, Common/Galkan, low-light vision, +2 Intimidate and war-pick/Galkan racial weapon proficiency. Optional bonus languages now use the source list (Dwarven, Elvaan, Giant, Goblin, Lalafellan, Orc), limited by a positive Intelligence modifier and connected to the active Languages trait.

Corrected Mining Servitude: the source gives +2 only to Profession (miner). The previous broad automatic effect gave the bonus to every Profession row. It is now an explicit manual specialty benefit, so unrelated professions receive no automatic bonus. The player may record the miner specialty and its benefit on a chosen Profession row. Metalworker remains conditional to checks involving metal.

Hardy, Stability, Hatred and Relentless remain conditional/manual. Ferocity’s below-zero trigger, once-per-day use and recovery, the armor/encumbrance speed exception and reincarnation need manual adjudication. No automatic global save, CMD, attack, death-state or skill changes are introduced for those conditions. Alternate traits and favored rewards require separate verified milestones; the wizard and server guard unsupported alternate scope.
