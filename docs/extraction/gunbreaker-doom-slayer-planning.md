# Gunbreaker / Doom Slayer integration

Source pages:
- https://finalfantasyd20.com/classes/hybrid-classes/gunbreaker/
- https://finalfantasyd20.com/classes/hybrid-classes/gunbreaker/archetypes/doom-slayer/

Galka's standard race traits are already supported in character creation.
Gunbreaker and its Doom Slayer archetype require verified class and archetype adapters for creation and level-up. Keep higher-level features disabled until all mandatory choices and feature replacements have been implemented.
