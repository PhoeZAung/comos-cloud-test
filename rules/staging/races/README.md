# Unapproved FFd20 race staging files

17 newly extracted races from batches 01–06 are stored here as independent .race.json files. Every definition remains `needs_review` with `coverage: partial`. They **are not enabled or imported**: `rules/manifest.json` continues to reference only Dwarf, Elvaan and Galka. Do not add staging files to the runtime registry until their conditional modifiers, alternate replacements, heritage rules, races with dependency requirements and favored-class links have been independently checked and tested.

Known open issue: Beastkin could not be fully sourced and remains **excluded**. See each JSON review.issues and the accompanying extraction reports for outstanding work. Extracted class data for Astrologian and Berserker remains separate and not enabled.

No Railway integration is required or intended.
